            学生的选课行为与各行为的选课操作方法

                学生的选课行为可分为四种，分别是：正常选课，补修选课，重（复）修选课，提前修
              读选课。
                说明：
                                            2.1 正常选课
                指学生按照教学计划（人才培养方案）中进度要求首次选择修读该课程。
                ★正常选课操作方法★
                 只有一种，进入“自主选课”，点击查询后，所显示的课程为可选课程，有关“自主选课”
                 操作界面介绍请参考3.1。
                                      2.2 补修选课
                指学生因转专业或其它原因错过了年级专业下课程正常修读时间而申请补充修读该课程
              的选课方式。
                ★补修选课操作方法★
                 进入“自主选课”，点击查询后，所显示的课程为可选课程，有关“自主选课”操作界面介
                  绍请参考3.1。
                                      2.3 重（复）修选课

指学生首次修读该课程时其成绩不合格（不理想）再次修读该课程的方式。
                ★重（复）修选课操作方法★
                允许两种。
                 第一种方法：进入“自主选课”，点击查询后，所显示的课程为可选课程，有关“自主选
                 课”操作界面介绍请参考3.1。
                 第二种方法：进入“重修报名（选课）”，输入相应的课程号后，所显示的课程为可选课
                程，直接进行重修选课即可，有关“重修报名（选课）”的操作方法请参考3.2。
                两种方法选课成功后均视为选课有效。
                                      2.4 提前修读选课
                指学生在完成规定的学习进度要求的情况下，提前选择本专业高年级课程进行修读的选
              课方式。
                ★提前修读选课操作方法★
                 只有一种，进入“自主选课”，点击查询后，所显示的课程为可选课程，有关“自主选课”
                 操作界面介绍请参考3.1。
                                      2.5 退课
                ★退课操作方法★
                 学生可对已选上或待筛选的课程进行退选，操作方法见3.3。
                                      2.6 个人课表或筛选查询
                 学生已选上或待筛选的课程均会反映到学生个人课表，其中已选上显示为“蓝色字体”，
                待筛选显示为“红色字体”，个人课表查询与筛选结果查询见3.4。
                慕课类课程的上课网址可以在选课结果或课表场地安排中查看。
            选课、退课与课表查询学生选课主要在“自主选课”或“重修选课”中进行，在“重修选课”中进行的选课行为（重
               修或补修选课），其成绩记载“重（复）”字，在“自主选课”进行的重修选课行为其成绩亦记载
                “重（复）”字，补修则不记载。
